## 1. brainstorming 확정 결정 (사용자 선택)

| 축 | 결정 |
|---|---|
| 무스크롤 기준 | **데스크톱(1280×720+) 무스크롤 보장** — 모바일(375px)은 같은 구조 유지, 세로 스크롤 허용 |
| 화면 패러다임 | **병원 맵 허브** — 개원 전 빈 병원 맵이 화면 전체. 원장 책상 탑다운(신규 아트 필요)·압축 그리드(대시보드 = 웹 느낌)는 기각 |
| 이름 입력 | **맵 현판에 통합** — 별도 NAME 화면 삭제, 화면 수 2→1 |

## 2. 화면 구성 — 1화면 3밴드

```
현판(이름 입력, ~60px) → 병원 맵(16:9, max-w-4xl ≈ 496px) → 하단 바(장부·자격·개원, ~70px)
```

- 1280×720에서 합계 ≈ 630px < 720px — **무스크롤 보장**. 검증 게이트: 브라우저 실측 `scrollHeight ≤ clientHeight`(§7).
- **같은 병원 공간의 연속**: 개원 전 = 빈 병원(미채용 방은 어두운 빈 방), 채용할수록 방이 밝아지고 의사가 나타나며, 「개원」 후 그 맵이 그대로 RECEIVING 화면이 된다. 위저드가 게임 밖 폼이 아니라 게임 공간 안의 행위가 된다.
- **현판** = 병원 이름 입력. 명조(입력 즉시 판정으로 선다 — v1 규칙 유지), 중앙 정렬, 빈 현판 placeholder. 이름이 비면 개원 불가(기존 `isSetupReady`가 이미 검사).
- **하단 바** = 한 줄: 채용 예산 장부(paper-card 압축 · 초과 시 「예산 초과」 도장 유지) · 자격 현재 등급 · 「병원 개원」 버튼. 자격 사다리 4단 전체 나열은 공간상 제거하고 현재 등급만 표시(사다리 학습은 등급이 바뀌는 순간의 변화로 전달 — show-don't-tell).

## 3. 방 클릭 → 지원서 오버레이 (한 번에 한 과)

- 맵의 방(8칸)이 클릭 타깃. 클릭하면 **중앙 오버레이**로 그 과 지원서 4장이 펼쳐진다 — 결정 카드가 이미 중앙 오버레이 문법(#105)이라 게임 내 관습과 일치.
- 지원서 = **세로형 서류 카드**(paper-card): 증명사진(픽셀 초상, 크게) 상단 → 이름(명조)·연차 → 한 줄 경력 → 계약금·진료 소요 배율. 데스크톱 4장 가로, 모바일 2×2.
- 탭 = 「채용」 도장 토글(v1 로직·stamp 클래스 그대로, `aria-pressed`). 상한 도달 시 미채용 카드 비활성(v1 동일).
- 오버레이 헤더에 과명 + 소계(n/상한 · 금액), 닫기 버튼 + Esc + 배경 클릭으로 닫힘.
- 채용/미채용 상관없이 방은 항상 클릭 가능(재조정 가능). 32장이 동시에 화면에 없으므로 모바일도 같은 구조로 성립한다.

## 4. 채용 피드백이 맵에 산다 — 이 화면의 게임 루프

- 도장을 찍는 순간 **그 방에 그 지원자의 픽셀 아바타(머리·피부 변주 얼굴)가 나타난다**(오버레이 뒤 맵에 즉시). 반려하면 사라진다.
- 채용 과는 방이 밝아진다(`staffed` — 기존 맵 규칙 재사용). 미채용 과는 어두운 빈 방.
- 하단 장부·자격은 실시간 갱신(로직 v1 그대로, 표시만 압축).

## 5. 구조 — 게임 로직 0줄

- **신규 `deriveSetupScene(hired: string[], beds?): MapScene`** (hospitalMap.ts): `hiredIds`에서 MapScene을 직접 합성. rooms(staffed = 그 과 채용 > 0 · 조명 DAY·전부 lit), beds(빈 침대), avatars(채용 지원자 = 자기 방 안 `zone:'ROOM'`·`busy:false`·`candidateId` 변주), waitingCount/Overflow 0. 순수·결정론. `CANDIDATES` 임포트는 순환 없음(candidates.ts는 types만 임포트).
- **`HospitalMap`에 옵셔널 `onRoomClick?: (dept: DeptKey) => void`**: 전달 시 방이 `<button aria-label="○○ 지원서 보기">`로 렌더, 미전달(RECEIVING) 시 현행 `<div>` 그대로 — RECEIVING 화면 0 변경.
- **SetupWizard 전면 재작성(표시만)**: 상태 = `hospitalName`·`hired`·`openDept`(오버레이). `draft` 파생·`onComplete(draft)` 단일 기록 지점 계약은 v1 그대로. NAME 단계 분기 삭제.

## 6. 반응형·접근성

- 모바일 375px: 3밴드 구조 유지(맵 축소 — 방 라벨 9px 규칙 기존 그대로), 오버레이 카드 2×2, 오버레이·페이지 세로 스크롤 허용(사용자 확정).
- 방 버튼 `aria-label` · 오버레이 `role="dialog"` + Esc 닫기 + 배경 클릭 닫기 · 지원서 `aria-pressed` · focus-visible 링 전부 유지.
- `prefers-reduced-motion`: 맵의 기존 배회 규칙이 이미 처리(신규 애니메이션 추가 없음 — 도장은 정적 표시).
