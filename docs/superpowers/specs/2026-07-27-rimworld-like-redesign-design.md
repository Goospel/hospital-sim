# 림월드형 전면 재설계 — 설계 스펙

> **결정(2026-07-27, 사용자)**: 현행 콜 카드 루프 게임이 재미없다. 림월드의 재미 4요소(자율 폰 · 건설/배치 · 위기 이벤트 · 개성 서사)를 전부 가져오는 **전면 전환(배수진)** — 기존판을 안전판으로 남기지 않고 새 방향으로 8/10 제출. 접근 3안(A 풀 슬라이스 / B 폰 우선 / C 건설 우선) 중 **A안 채택**.
>
> 이 문서가 새 게임 정의의 단일 출처다. [game-concept.md](../../concept/game-concept.md)의 콜 카드 루프 서술은 이 전환으로 대체된다(메시지·톤·AI 2콜 원칙은 계승).

## 0. 계승하는 것 — 컨셉은 그대로, 표현을 바꾼다

- **메시지 불변**: "개인이 최선을 다해도 구조 때문에 나쁜 결과가 나온다." 필수의료 경제(옳은 의료를 할수록 장부가 나빠짐) · 피로가 사람을 갈아넣는 구조 · 지역 인력 풀 소진.
- **AI 원칙 불변**: 판정 = 결정론 코드 / 연출·선택 = LLM (2콜 분리). 게임 상태 전이는 절대 LLM이 정하지 않는다. 무키·타임아웃 시 결정론 폴백으로 완주 가능(GitHub Pages 정적 배포 유지).
- **대회 제약**: NAN 2026 사전 과제, 마감 2026-08-10, 솔로. 심사축 = AI 활용(디렉팅 B축 스파인 유지 — "AI를 어디까지 믿고 어디서 끊는가").

## 1. 시뮬 코어 — 타일 세계와 시간

- **타일 그리드** 약 48×32. 타일 = 바닥종류 / 벽 / 가구 / 통행 가능 여부. 시작은 거의 빈 부지, 플레이어가 방을 지어 채운다.
- **실시간 + 일시정지 + 배속**(1×/3×). 스페이스로 언제든 정지 — 간접 통제의 전제.
- **시뮬은 순수 함수** `tick(world, dt, seed)`가 전부 굴린다. React는 렌더 전용. 시드 고정 결정론 → 기존 TDD·회귀 방식 그대로 적용.
- **하루·주 리듬 유지**: 9~19시 외래, 야간 응급만. 주간 결산(장부·사직·채용)이 "계절" 역할.

## 2. 폰 — 자율 행동

- **폰 종류**: 의사(고용) · 환자(손님) · 거리 보행자(장식·기존 유지). 간호사·행정직은 v2 보류(폰 종류 증가 = 작업 AI 제곱 복잡화).
- **욕구 3개**: 피로 · 허기 · 스트레스. 임계 초과 시 스스로 일을 끊고 휴게실·식당으로. **기존 피로 시스템(표준강도분 · 감속 곡선)을 심장으로 재사용.**
- **작업 AI**: 의사별 × 작업종류(진료/응급/휴식) 3단 우선순위 토글. 플레이어는 폰 직접 조작 불가 — 이 표와 배치로만 개입.
- **길찾기**: 그리드 A*. 맵이 작아 리스크 낮음.
- **환자 라이프사이클**: 입장→접수→대기(의자)→호출→진료→수납→퇴장. 응급은 침대 직행. 대기 한계 초과 시 이탈(기존 `LEFT_WAITING` 계승), 응급은 악화→사망. "매일 누군가는 못 받는다"가 화면에서 걸어나가는 사람으로 바뀐다.
- **개성**: 폰마다 특성 2개(수치 효과는 결정론 — 예: 워커홀릭 = 피로 임계↑·스트레스 축적↑) + 사연 한 줄. 표면 서사는 LLM(§4).

## 3. 건설·배치 — 방 단위

- **사각형 드래그 → 방 타입 지정**(진료실[과 선택] · 병동 · 대기실 · 휴게실 · 접수). 벽 한 장·가구 한 개 단위 건설은 절단 — **방 타입이 가구 자동 배치를 결정**한다. 2주를 성립시키는 최대 절단선.
- **경제는 기존 그대로**: 만원 단위, 건설비 + 과별 고정비 + 진료 수익(`CALL_ECONOMICS` 계승). 개원 자본에서 시작, 금고 음수 연속 2주 = 폐업(기존 규칙).
- **배치→성과 인과 3개(전부 걸어야 성립)**: ① 대기실 의자 수 = 수용 용량 ② 진료실↔병동 거리 = 이동시간 = 처리량 ③ 휴게실 거리 = 피로 회복 빈도.

## 4. AI 스토리텔러 — 심사축

- **결정론 이벤트 엔진(코드)**: 이벤트 풀(대량 응급 · 전염병 유행 · 의료소송 · 사직 파동 · 인근 병원 폐업→유입 급증 등)마다 발동 가능 조건·수치 효과를 코드가 확정. 불공정 조합(병상 0 + 대량 응급)은 가드레일 차단. LLM은 상태를 못 바꾼다.
- **LLM 디렉터**: 상황 요약(장부·피로 분포·인력 구성·이벤트 이력)을 읽고 후보 중 **무엇을 언제 던질지 선택 + 연출문 생성**. 구조적 약점을 찌르는 페이싱 판단이 "AI를 빼면 무너지는가"의 답 — 빼면 가중 랜덤 폴백으로 강등돼 상황을 읽는 맛이 사라진다.
- **무키 폴백**: 가중 랜덤 + 사전 작성 연출문. Pages 정적 배포에서도 완주.
- **폰 서사 표면**: 사직 편지 · 환자 항의문을 그 폰의 특성·이번 판 이력으로 LLM 생성(사건당 1회 · 전부 폴백 문장 보유).

## 5. 기존 자산 이식 지도

| 살린다 (순수 함수 코어) | 은퇴한다 |
|---|---|
| 과 카탈로그 · 수가/고정비 경제(`types` · `receiving`의 경제 상수) | 콜 카드 5통 루프 · `ReceivingPhase` UI 전반 |
| 피로 표준강도 · 감속 곡선 · 사직 규칙 | `daysim` 콜 스케줄(→ 환자 도착 생성기로 대체) |
| 전국 인력 풀 · 채용 후보(`system` · `candidates`) | 고정 8칸 맵 · `deriveMapScene`(→ 타일 세계) |
| 하드락 판정 원칙(`adjudicate` — 배후과 없으면 응급 불가) | 빨리감기 · 콜 사이 스킵 |
| 장부 · 과별 영수증 · 주간 결산 · 폐업 규칙 | SETUP 위저드(→ 인게임 건설+채용으로 흡수) |
| 픽셀 스프라이트 · 아바타 CSS 이동(`PixelSprite`) | |

핵심: **경제·판정·피로·사직 = 메시지를 만드는 수학은 전부 생존.** 바뀌는 건 플레이어를 만나는 방식(카드·숫자 → 걸어다니는 사람·지어지는 건물).

## 6. 일정 절단선 (2주)

- **1주차(7/27~8/2) "돌아가는 병원"**: 타일맵 + 틱 엔진 + A* / 방 건설 최소(진료실·대기실) / 환자 흐름 / 의사 자동 진료. 이 시점에 게임이 관찰 가능해야 함.
- **2주차(8/3~8/9) "림월드가 되는 주"**: 욕구·우선순위 토글 / 경제·피로·사직 이식 / 스토리텔러 결정론판→LLM 레이어 / 폐업·주간 결산 / 영상·PDF·배포.
- **8/10 제출.** 배수진이지만 **매 시점 완주 가능한 빌드 유지**가 유일한 안전장치 — 매일 저녁 "지금 상태로 제출 가능한가" 점검.

## 7. 테스트 전략

- 시뮬 코어 전부 TDD: 시드 고정 결정론 스냅샷 + 불변식(예: "의사 0명이면 진료 0건" · "피로 포화면 반드시 휴식 행동" · "LLM 유무와 무관하게 게임 상태 전이 동일").
- UI는 브라우저 실측(콘솔 0 · 모바일 375px).

## 8. 보류(⏸ — 본선 후보)

- 간호사·행정직 폰 / 벽·가구 단위 건설 / 폰 관계(호감·갈등) 그래프 / 음성 TTS / N주 너머 장기 캠페인 밸런싱.
