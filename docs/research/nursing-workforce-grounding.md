# 간호인력 — 등급제·잔류 실패·PA 법제화 근거

> **산출**: 경량 리서치(웹 검색 6갈래 + 원문 대조 1건 적대 검증), 2026-07-29.
> **목적**: 간호사 축 도입(수납 기능 + 처우·권한 딜레마)의 근거. 발단은 사용자 질문 *"카운터·휴게실이 기능을 하는가"* → *"진짜로 붙이려면 간호사가 필요하고, 처우·권한 쟁점도 있다"*.

## ⚠️ 적대 검증에서 교정한 것 (1건) — 이 문서가 생기기 전의 구두 주장 정정

세션에서 나는 *"감산액이 간호사 인건비보다 싸면 안 뽑는 게 이득이라, 중소병원이 등급 미달을 감수한다"*고 말했다. **그 계산 논리는 확인한 출처 어디에도 명시돼 있지 않다.** 메디칼타임즈 원문 대조 결과, 기사가 실제로 말하는 메커니즘은 다르다:

> 등급제(+간호간병통합병동·대학병원 분원 설립)가 **대형병원의 간호사 흡수 경쟁**을 부추긴다 → 중소병원은 웃돈을 줘도 **구하지 못한다** → 등급 미달 → **감산**(연 130억 규모, 그중 90%+가 중소병원) → 재정 악화 → 처우가 더 나빠져 더 못 구한다.

즉 "안 뽑는다(선택)"가 아니라 **"못 뽑는데 벌까지 받는다(악순환)"**다. 게임화할 때는 이 교정된 방향을 쓴다 — 사람을 더 쓰게 하려는 규칙이, 사람을 구할 수 없는 병원에는 **벌금으로만 작동**한다. 이쪽이 게임 명제("개인이 최선을 다해도 구조 때문에 나쁜 결과")에 원래 주장보다 더 정확히 맞는다.

*단, "감산 감수가 합리적 선택이 되는 병원도 있다"는 가설 자체를 기각한 것은 아니다 — 근거를 못 찾았으므로 게임·문서 어디에도 사실로 적지 않는다는 뜻이다(§4-①).*

## 1. 현실에서 성립하는 「방향」 (그대로 써도 됨)

### 축 A — 간호관리료 차등제(간호등급제): 인력 수가 곧 수가 배율이다

- 1999년 도입. 일반병동 간호인력 확보 수준에 따라 **7개 등급**으로 나눠 **입원료를 차등 지급** — 5등급 이상은 기준등급(6등급) 대비 **10~70% 가산**, 7등급은 **5% 감산**. — [의학신문](http://www.bosa.co.kr/news/articleView.html?idxno=2078207)
- 산정현황 **미신고 기관은 '등급 외'로 10% 감산**(2020-01부터 강화). 미신고 100곳·7등급 542곳 시점 기록. — [의협신문](https://www.doctorsnews.co.kr/news/articleView.html?idxno=143916)
- 산정 기준이 **병상 수 → (지방 병원급은) 환자 수**로 전환 — 병상가동률 낮은 지방 중소병원이 구조적으로 불리했던 것의 보정. — [보건복지부](https://mohw.go.kr/board.es?act=view&bid=0027&list_no=339406&mid=a10503010100&nPage=647&tag=)
- **감산의 몫은 중소병원이 진다**: 2018년 130.6억 · 2019년 122.0억 · 2020년 상반기 56.1억 삭감, 중소병원 비중 **92%**. — [메디칼타임즈](https://www.medicaltimes.com/Mobile/News/NewsView.html?ID=1136988) · [데일리메디](https://www.dailymedi.com/news/news_view.php?wr_id=887433)

### 축 B — 잔류 실패: 면허는 많은데 병원에 없다

- 면허 간호사 **52.7만 명** 중 의료기관 활동 **약 51~54%** — OECD 평균 활동률 **68.2%**에 크게 못 미침. 유휴간호사 **20.4만 명**(2024). — [MDtoday](https://www.mdtoday.co.kr/news/view/1065589702819576) · [에포크타임스](https://www.epochtimes.kr/2025/08/719979.html) · [간호신문](http://m.nursenews.co.kr/page/ArticleDetailView.asp?sSection=61&idx=36469)
- **신규간호사 1년 이내 사직률 52.8%**(2021) — 2014년 28.7% → 2016년 35.3% → 2018년 42.7% → 2020년 47.4%로 **매년 상승**. 사직 사유 1위는 업무부적응(32.6%). — [의학신문](http://www.bosa.co.kr/news/articleView.html?idxno=2198755)
- 병목은 **양성이 아니라 잔류**다: 간호대 배출은 계속되는데 절반이 1년 안에 무너지고, 면허의 절반이 현장 밖에 있다. (태움·3교대는 이 축의 정성적 배경 — §4-④)

### 축 C — 배치 수준: 1인당 환자 수가 OECD의 약 1.6배, 법정 상한은 없다

- 한국 병원 간호사 1인당 평균 담당 환자 **약 13명** vs OECD 평균 **약 8명**(스위스 6.1 · 독일 6.6 · 프랑스 8.6). 급성기에선 20명+ 사례. — [서울간호학보사](https://hakbosa.snjc.ac.kr/?p=2109)
- 인구 1,000명당 활동 간호사 **4.4명** vs OECD 평균 **8명**(2020, 인권위 인용). — [뉴시스](https://www.newsis.com/view/NISX20230904_0002436466)
- 의료법 정원 기준은 **연평균 1일 입원환자 수 ÷ 2.5**뿐이고, **간호사 1인당 환자 수의 법적 상한은 없다**. — [서울간호학보사](https://hakbosa.snjc.ac.kr/?p=2109)

### 축 D — PA(진료지원) 법제화: 회색지대가 사후에 제도가 됐다

- 시간 순서가 논점이다: **① 전공의 집단사직(2024-02) → ② 그 공백을 메우는 '간호사 업무 시범사업' 즉시 시행 → ③ 간호법 제정(2024-09) → ④ 시행(2025-06-21) → ⑤ 43개 행위 고시(2026-07)**. 필요가 먼저 있었고 법이 뒤따랐다. — [정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148967956) · [의학신문](https://www.bosa.co.kr/news/articleView.html?idxno=2265084)
- 시범사업 초기 **1만~1.1만 명 → 2024-12 기준 1만 7,103명**으로 급증. — [닥독닥](http://www.docdocdoc.co.kr/news/articleView.html?idxno=3034996)
- 제도의 형태: 수행 주체는 **전문간호사 + 진료지원전담간호사**(임상 3년 + 지정 교육과정), 병원은 **진료지원업무 운영위원회** 설치 + **직무기술서** 작성 의무, **43개 행위**(피부봉합 등) 목록 고시. — [보건복지부](https://mohw.go.kr/board.es?act=view&bid=0027&list_no=1491218&mid=a10503010100&nPage=1&tag=) · [한국일보](https://www.hankookilbo.com/news/article/A2026071014500003511) · [메디칼타임즈](https://www.medicaltimes.com/Main/News/NewsView.html?ID=1169692)

## 2. 「구체 수치」 각색 허용 범위 (부호만 지키면 됨)

| 실제 수치 | 각색 허용 범위 |
|---|---|
| 등급 7단계, 가산 10~70% · 감산 5~10% | 단계 수·%는 게임 규모에 맞게 축약 가능. **"인력이 수가 배율을 정하고, 미달은 깎인다" 유지** |
| 감산액의 92%가 중소병원 | 액수 각색 가능. **"벌은 못 구하는 쪽이 받는다" 유지** |
| 신규 1년 사직률 52.8%·매년 상승 | %는 바꿔도 됨. **"신규의 약 절반이 1년 안에 나간다 + 과로할수록 오른다" 유지** |
| 1인당 환자 13명 vs OECD 8명 | 게임 스케일로 환산 가능. **"기준 초과 배치가 기본 상태" 유지** |
| PA 1.7만 명·43개 행위 | 게임에선 인원수보다 **"의사 공백을 간호사가 메우고, 결정은 병원이 한다" 유지** |

## 3. 게임 이식 시 알려진 어긋남 (각색 필요)

- **간호관리료는 '입원료' 가산이다.** 이 게임의 병원은 외래 중심(입원은 응급 병동뿐)이라 그대로 이식하면 근거와 어긋난다. → 게임에선 **"간호등급이 병원 수가 배율에 걸린다"로 일반화**하고, 이 각색을 제출 문서에 고지한다. 부호(인력 미달 → 수입 삭감)는 유지된다.
- **게임의 시간 해상도(1주)** 에서 "1년 내 사직률"은 그대로 못 쓴다 → 기존 사직 기계(피로 누적 → 사직)에 **신규 보정**(입사 초기 사직 확률 가중)으로 옮기는 것이 부호 보존 번역.

## 4. 미확인·약한 근거 (사실로 쓰지 말 것)

1. **"감산 감수가 인건비 절약보다 이득"이라는 명시적 손익 비교** — 머리말의 적대 검증 참조. 출처 미확보. 게임 대사·제출 문서에서 이 인과로 서술하지 않는다.
2. **야간간호료·간호사 처우개선비** — 제도의 존재만 확인([JKANA 논문 제목](https://jkana.or.kr/DOIx.php?id=10.11111/jkana.2021.27.3.191)). 세부 수치·작동 방식 미조사. 쓰려면 추가 리서치.
3. **간호간병통합서비스** — 대형병원 간호사 흡수의 한 원인으로 언급됐을 뿐 자체 조사 안 함.
4. **태움** — 신규 사직률·업무부적응 통계가 정황 근거일 뿐, 태움 자체의 정량 출처는 이번 조사에 없다. 게임에선 **단어를 쓰지 않고** 기계(피로·신규 사직 가중)로만 표현한다 — 실존 직군에 대한 낙인 위험이 정보 이득보다 크다.
5. **간호등급별 실제 등급 분포의 최신값** — 7등급 542곳은 시점이 오래됐다(2020년 전후). 제출 문서에 분포를 적으려면 재확인.
