# T-150 · Math.random 전역 고정이 React 클릭 전체를 소리 없이 죽인다

- **증상**: 제출 영상 촬영 하네스(2026-08-03)에서 배경 그림 추첨을 고정하려고
  Playwright `addInitScript`로 `Math.random = () => 0.1`을 걸자 **게임의 모든
  클릭이 무반응**이 됐다. 지역 점을 눌러도 `aria-pressed`가 안 바뀌고, 콘솔
  에러·경고 0건 — 페이지는 멀쩡히 렌더되는데 상호작용만 전부 죽는 무성 실패.

- **원인**: react-dom은 **모듈 평가 시점**에 `Math.random()`으로 내부 이벤트
  프로퍼티 키(`__reactProps$<랜덤>`, `__reactFiber$<랜덤>`)를 만든다. dev
  환경에는 react-dom 인스턴스가 둘이다(앱 번들 + next-devtools가 품은 사본).
  `Math.random`이 상수면 **두 인스턴스가 같은 키를 생성**하고, 이벤트 위임이
  DOM 노드에서 키로 프로퍼티를 읽을 때 다른 인스턴스가 쓴 값을 집어 핸들러에
  도달하지 못한다. 랜덤 키는 장식이 아니라 인스턴스 격리 장치였다.

- **해결**: 전역 고정을 버리고 **게임이 실제로 `Math.random`을 부르는 한
  지점**(배경 추첨, `SimGame.tsx`의 `createWorld` 호출 직전) 앞에서만 패치하고
  직후에 원본으로 되돌렸다(`scripts/video/capture.mjs`의 `pickRegion` 참조).
  게임 규칙은 어차피 시드 해시라 `Math.random`과 무관 — 고정이 필요한 건 배경
  3종 추첨뿐이었다.

- **재발방지**: 결정론을 위해 전역 내장(`Math.random`·`Date.now` 등)을 고정할
  땐 **"내 코드만 그걸 쓰는 게 아니다"를 전제**하라 — 라이브러리가 초기화
  시점에 그 내장으로 식별자를 만들면 상수 고정이 충돌을 낳는다. 기본값은 호출
  지점 국소 패치(쓰고 즉시 복원)이고, 전역 고정은 페이지 로드 전 값이 필요한
  경우(웹 하네스의 시드 주입 등)로 한정한다.
