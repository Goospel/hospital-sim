# T-155 · UI 리팩터가 자동화 하네스를 조용히 깬다 — 셀렉터가 옛 구조에 묶여 있었다

- **증상**: 제출 문서 스크린샷을 다시 찍으려고 `scripts/video/capture.mjs`의 조작
  절차를 재사용했더니 **두 자리에서 30초 타임아웃**으로 죽었다.
  ① `hireRoster` — `dlg.locator("section").filter({ has: heading(과이름) })`이 0건.
  ② `pickTool` — 첫 호출은 통과하는데 **둘째 호출부터** `btn("건설")`을 못 찾는다.
  둘 다 에러가 "요소가 없다"라서 *게임이 깨졌나*로 읽히지만, 게임은 멀쩡하고
  **하네스만** 낡았다. `npm test`·`tsc`·`next build` 전부 green이라 아무도 안 알려준다.

- **원인**: 같은 날 머지된 두 PR이 하네스가 **암묵적으로 의존하던 DOM 구조**를 걷어냈다.
  ① **#202(채용 과 탭)** — 과별 `<section>` + `<heading>` 넉 장을 세로로 쌓던 구조가
  탭 4개 + 고른 과의 선반 하나로 바뀌었다. 헤딩이 사라졌으니 `filter({has: heading})`은
  영영 0건이다.
  ② **#201(팔레트 드릴다운)** — 아코디언의 `aria-expanded` 토글이 통째로 없어지고,
  계층이 **상태가 아니라 파생**이 됐다(`simHud.paletteLevel({section, tool, roomType})`).
  옛 `openSection`은 `aria-expanded !== "true"`면 누르는 식이라, 속성이 **아예 없어진**
  지금은 `null !== "true"`로 **항상 누른다**. 게다가 BUILD 계층에서는 「‹ 건설」
  **뒤로가기 버튼의 접근성 이름이 "건설"**이라(꺾쇠는 `aria-hidden`) 같은 이름의 버튼이
  뜻만 정반대로 서 있다 — 무장하러 누른 것이 **최상위로 나가는** 클릭이 된다.

- **해결**: 저장소 밖 복사본에서 **계층을 화면으로 판정**하도록 이식했다(코어·`scripts/`
  무변경). 상태를 못 읽으니 "지금 무엇이 서 있는가"로 대신 판정한다.
  ```js
  const backBtn = () => page.locator("button").filter({ hasText: "‹" });
  async function toBuild() {                        // BUILD 계층까지 올라간다
    for (let i = 0; i < 5; i++) {
      if (await btn("벽").count()) return;          // 도구 목록이 서 있으면 BUILD
      if (await backBtn().count()) await backBtn().first().click();
      else await page.getByRole("button", { name: /^건설/ }).click();
      await page.waitForTimeout(90);
    }
    throw new Error("BUILD 계층에 못 갔다");
  }
  ```
  요점 둘: **뒤로가기는 접근성 이름이 아니라 `innerText`의 「‹」로 잡는다**(이름은
  현재 계층명이라 도구 버튼과 겹친다). **도착 판정은 「벽」 버튼의 존재**로 한다 —
  `paletteLevel`이 파생이라 화면에 선 목록이 곧 계층이다. 채용은 `section` 대신
  `button[aria-pressed]` 탭을 `HIRABLE_DEPTS` 순서로 인덱싱해 누른다. 이식 후
  빈 부지 → 개원 체크리스트 **6/6**까지 자동 완주했다.

- **재발방지**: ⚠️ **`scripts/video/capture.mjs`는 UI 계약의 소비자인데 아무 계측기도
  그것을 안 겨눈다.** 컴포넌트 테스트는 컴포넌트를, 하네스는 **화면 전체의 조작
  경로**를 본다 — 후자가 깨져도 전자는 전부 green이다. 그래서 깨진 사실이 드러나는
  시점이 *고칠 여유가 가장 없는 날*(마감 직전 영상·사진 재촬영)로 밀린다.
  ① **팔레트·채용·개원 흐름의 DOM 구조를 바꾸는 PR은 `scripts/video/capture.mjs`를
  같은 PR에서 함께 본다**(최소한 "이 셀렉터가 아직 서 있나"만). 오늘의 넷(#201~#204)은
  넷 다 그 흐름을 건드렸는데 넷 다 하네스를 안 봤다.
  ② **하네스가 `aria-expanded`·헤딩 텍스트처럼 "구현이 바뀌면 사라지는 것"에 묶이지
  않게 한다.** 접근성 이름·`aria-pressed`처럼 **화면이 사용자에게 하는 약속** 쪽이
  오래 산다 — 실제로 `getByRole("dialog", {name: "개원 준비 — 전국 인력 시장"})`과
  `/채용$/`는 두 PR을 그대로 통과했다.
  ③ 이번 이식은 **저장소 밖 복사본에만** 있다(작업 범위가 문서였다). 다음에 영상을
  다시 찍는 사람이 같은 30초 타임아웃을 다시 만난다 — 그때 이 항목의 코드를
  `capture.mjs`에 반영한다. [changeLog 2026-08-05 「제출물 ③·④를 오늘의 UI에 정합」](../changeLog.md)에도
  같은 숙제를 적어 뒀다.
