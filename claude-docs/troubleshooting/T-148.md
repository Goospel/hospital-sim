# T-148 · vitest 1596건 전건 초록인 코드가 tsc에서 죽었다 — 테스트는 타입을 안 본다

- **증상**: `candidate.ts`에 과별 빈 배열 표를 만드는 한 줄을 썼다.

  ```ts
  return Object.fromEntries(
    HIRABLE_DEPTS.map(key => [key, []]),
  ) as Record<SimDeptKey, number[]>
  ```

  `npx vitest run` — **48파일 1596건 전건 통과**. 그런데 `npx tsc --noEmit`은 죽는다:

  ```
  src/sim/candidate.ts(47,10): error TS2352: Conversion of type '{ [k: string]: never[]; }'
  to type 'Record<SimDeptKey, number[]>' may be a mistake because neither type sufficiently
  overlaps with the other.
  ```

  (이 절의 두 수치는 이 항목을 쓰면서 **실제로 되돌려 재현한 값**이다 — 같은 트리에서
  vitest 1596/1596 초록 · tsc 1건 에러.)

  타입 쪽 원인 자체는 사소하다: 리터럴 `[]`가 `never[]`로 좁혀져 `number[]`와 겹치는 면이
  없고, `as` 캐스트는 **겹치지 않는 두 타입 사이에서는 거부된다**. `[] as number[]`로 원소
  타입을 미리 넓히면 끝난다.

- **원인**: 사소한 것은 문법이고, 함정은 **초록불이 무엇을 뜻하는가**다.

  **vitest는 타입 검사기가 아니다 — 트랜스파일만 한다.** 타입 표기는 실행 전에 통째로
  지워지므로, 타입이 아무리 틀려도 런타임 동작이 맞으면 테스트는 전건 초록이다. 위 코드도
  런타임에는 정확히 의도대로 돌아간다(과별 빈 배열 표가 실제로 만들어진다). 그래서 **테스트는
  이 결함을 원리적으로 못 잡는다** — 그물이 성긴 게 아니라 **다른 축을 재는 계측기**다.

  여기가 미끄러운 이유는 초록의 숫자가 클수록 안심이 커진다는 것이다. 1596건이 통과하면
  "이 트리는 건강하다"로 읽히는데, 그 1596건 중 **타입에 대해 한마디라도 하는 것은 0건**이다.

  ⚠️ **파이프라인이 뚫린 것은 아니다**(재현으로 확인): CI는 lint → test → **build**를 돌고,
  `next build`가 같은 줄에서 exit 1로 죽는다. 즉 이 결함은 **머지 전에는 반드시 잡힌다.**
  구멍은 CI가 아니라 **로컬 빠른 루프**에 있다 — 편집 사이에 `npm test`만 돌리면 타입 에러가
  몇 시간이고 초록 아래에 누적되고, 그 사실은 훨씬 느린 build를 돌릴 때에야 드러난다.

- **해결**: `[] as number[]`로 원소 타입을 명시하고(캐스트가 성립하도록 `never[]`를 없앤다),
  왜 그냥 `[]`면 안 되는지를 그 자리 주석에 남겼다. 그리고 이 브랜치의 **완료 게이트를
  `npm test` + `npx tsc --noEmit` + `npm run lint` + `npm run build` 넷으로** 고정했다.

- **재발방지**: **"테스트 전건 통과"는 "컴파일된다"를 함의하지 않는다.** 두 문장은 서로 다른
  계측기의 출력이고, 이 저장소에서는 축이 아예 갈라져 있다 — vitest는 **행동**을, tsc는
  **타입**을 잰다. 그래서 초록 숫자를 보고할 때 그것이 tsc를 대신하지 않는다는 것을 알고
  적어야 한다.

  실무 규칙 하나로 접으면: **타입 표기·제네릭·캐스트를 건드린 편집 뒤에는 `npx tsc --noEmit`을
  같이 돌린다.** 12초짜리 vitest 옆에서 tsc는 몇 초라 빠른 루프에 넣어도 리듬이 안 깨지고,
  안 넣으면 그 대가를 build 시점에 **여러 편집이 뭉친 채로** 치른다.

  이건 [T-068](T-068.md)이 말한 *"안 돌린 게이트의 침묵을 통과로 읽는다"*의 이웃 사례이되
  한 겹 더 고약하다. T-068은 게이트를 **안 돌린** 것이고, 여기서는 게이트를 **돌렸고 초록도
  받았다** — 다만 그 게이트가 애초에 그 결함을 볼 수 없는 종류였다. 침묵이 아니라 **자기
  소관이 아닌 것에 대한 초록**이라, 관측만으로는 구별되지 않는다.
