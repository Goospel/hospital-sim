# T-115 · 어두운 색을 밝히면 **파랑이 폭주**한다 — 휘도 가중치 0.0722의 함정

- **증상**: 배경 팔레트 60여 색을 휘도 7~19 대역에서 22~64 대역으로 옮기는 변환을 짰다. 목표 휘도는 정확히 맞았고 휘도 서열·간격을 잠근 테스트도 전부 통과했는데, 브라우저에서 보니 **인도가 보라색**(`#0e0d17` → `#2c2666`)이고 아파트 동이 **형광 보라**였다. 값은 스펙대로인데 색이 스펙과 다른 것을 말하고 있었다.

  같은 변환을 실내(방 바닥·벽)에 쓰자 더 심했다 — 병동 벽 `#957cdd`, 접수처 `#a68484`로 병원이 **사탕 가게**가 됐다.

- **원인**: 상대휘도 식의 채널 가중치가 **R 0.2126 · G 0.7152 · B 0.0722**로 극단적으로 비대칭이다. 파랑은 같은 밝기를 내려면 초록의 **약 10배** 값이 필요하다.

  변환 순서가 "채도를 올린 뒤 목표 휘도로 스케일"이었는데, 채도를 올리면 파랑 쪽으로 기운 색은 B가 커지고 R·G가 작아진다 → 휘도가 **떨어진다** → 목표를 맞추려는 계수 `k`가 커진다 → **B가 혼자 폭주한다**.

  ```
  sidewalk #0e0d17 = (14,13,23), L = 13.93,  목표 43.5
    채도 1.75배 → (11, 9, 32)  L = 8.3     ← 채도를 올려 휘도가 떨어졌다
      k = 43.5/8.3  = 5.24 → (58,47,168) = #2c2666   ← 보라
    채도 1.00배 → (14,13,23)  L = 13.93
      k = 43.5/13.93 = 3.12 → (44,41,72)  = #2c2948   ← 원래 색조 그대로
  ```

  둘째 원인이 있었다 — **밝은 면과 어두운 면에 같은 채도 상한을 쓴 것.** 같은 색조라도 휘도가 오르면 채도가 눈에 그대로 드러난다. 어두울 때 "보라 기운"이던 값이 140에서는 형광 보라가 된다. 눈에 보이는 양은 채도가 아니라 **채도 × 휘도**다.

- **해결**: 두 가지를 바꿨다.

  1. **채도를 거의 올리지 않는다**(1.22배). 색조 보존의 정확한 정의는 "채널 **비율** 유지"이고, 이 휘도 식은 채널 선형이라 **전 채널에 같은 계수를 곱하면 휘도만 정확히 그 배율로 움직이고 색조는 수학적으로 불변**이다. 별도 채도 보정이 필요 없다.
  2. **상대 채도 상한을 면의 밝기별로 나눈다** — `(max−min)/mean` 기준 배경(어두움) 0.50 · 실내(밝음) 0.24. 넘으면 회색축으로 lerp해 되돌린 뒤 다시 스케일한다.

  그리고 방향이 뒤집혔다: **색은 표면이 아니라 빛이 낸다.** 표면을 저채도로 두고 additive 발광 패스(창문·간판·전조등)가 채도를 지게 하는 것이 어두운 화면에서 훨씬 잘 읽힌다.

- **재발방지**: 팔레트를 대역 이동할 때 **휘도 단언만으로는 부족하다**. `backdropPalette.test.ts`가 잠그는 것은 휘도 구간·서열·간격이고 **색조·채도는 어떤 단언도 없다** — 그래서 이 회귀가 초록불로 통과했다. 채도 검사기를 붙이는 대신(무엇이 "과한 채도"인지는 면적·이웃색에 딸린 판단이라 숫자로 못 잠근다) 변환 쪽에 규율을 둔다:

  1. **색조 보존 = 전 채널에 같은 계수.** 채도 조정을 섞지 않는다.
  2. 채도를 꼭 올려야 하면 **상대 채도 상한을 밝기별로** 두고 그 값을 계산기 안에 주석으로 박는다.
  3. 팔레트 변환은 **반드시 브라우저에서 눈으로 본다.** 이 항목의 두 회귀 모두 테스트가 아니라 스크린샷이 잡았다.

  ⚠️ 절차 함정이 하나 더 있었다 — 상한을 0.72에서 0.50으로 고친 뒤 계산기를 다시 돌렸는데 **출력의 뒷부분만 확인하고** 앞부분(배경 팔레트)은 옛 출력을 그대로 소스에 붙였다. 그래서 실내는 0.24 판, 배경은 0.72 판이 섞인 채 커밋 직전까지 갔다(브라우저 검수가 잡았다). **생성기 출력을 소스로 옮길 때는 파라미터를 바꾼 뒤 전량을 다시 옮긴다** — 일부만 갱신하면 한 파일 안에 두 세대가 공존하고, 그건 diff로도 안 보인다.
