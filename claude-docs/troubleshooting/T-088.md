# T-088 · flex 중앙 정렬 + 스크롤 = 위가 잘린 채 닿지 않는 화면

- **증상**: 주간 결산 오버레이(7일 표 포함)가 작은 뷰포트에서 위쪽이 잘렸는데 **스크롤을 끝까지 올려도 위에 닿을 수 없었다.** DOM 실측: 900px 높이 자식의 `top = −434px`, 스크롤 가능 범위 465px — 스크롤을 내리면 오히려 더 나빠진다(−154px).

- **원인**: `overflow-y-auto` 컨테이너에 `flex items-center`(세로 중앙)를 주면, 자식이 컨테이너보다 클 때 **중앙 정렬이 자식의 절반을 컨테이너 시작점 위로** 밀어낸다. 스크롤 좌표계는 컨테이너 시작점(0)부터라, 음수 영역은 스크롤로 도달 불가다. 내용이 짧을 땐 정상으로 보여서(중앙에 예쁘게 뜸) 긴 내용이 처음 등장하는 순간까지 조용히 숨어 있는 함정이다.

- **해결**: 컨테이너를 `items-start`로 두고 **자식에 `my-auto`**를 준다 — 자식이 짧으면 auto 마진이 중앙 정렬을 재현하고, 길면 top이 0에서 시작해 정상 스크롤된다(수정 후 실측: top +16px, 스크롤 범위 915px). 리뷰가 수정 전/후 기하를 재현해 확인했다.

- **재발방지**: 모달·오버레이의 세로 중앙 정렬은 `items-center` 대신 **`items-start` + 자식 `my-auto`**를 기본형으로 쓴다. 내용 길이가 가변인 오버레이는 "뷰포트보다 긴 경우"를 DOM 기하(`getBoundingClientRect().top ≥ 0` + `scrollHeight` 도달 가능성)로 한 번 실측한다.
