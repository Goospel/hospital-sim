# T-081 · 이중 기재가 만든 상시 빨간불 — 오탐하는 게이트는 꺼진 게이트다

- **증상**: 글로벌 설정 레포(`~/.claude`, 백업용)의 `Backup integrity` 워크플로가 **5커밋 연속 failure**였다(2026-07-25~27). 그런데 아무도 몰랐다 — 다른 작업을 하다 로컬에서 CI 로직을 손으로 재현해 보고서야 발견했다. `origin/main` 자체가 위반 상태였으니, 그 사이 올라간 모든 커밋이 무검증으로 통과한 것과 같다.

- **원인**: 추적 허용 목록(whitelist)이 **두 곳에 적혀 있었다**.
  - `.gitignore` — `/*`로 전부 무시한 뒤 `!/hooks/` 식으로 여는 **실제 규칙**
  - `.github/workflows/integrity.yml` — 같은 목록을 옮겨 적은 **정규식** `^(\.gitignore|...|hooks/.+|templates/.+)$`

  `agents/`와 `docs/`를 새로 열 때 `.gitignore`만 고치고 정규식을 안 고쳤다. 그래서 CI가 정상 파일 4개를 "whitelist 밖 추적"으로 **오탐**했다.

  여기서 한 층 더 나쁜 일이 벌어진다. **오탐은 고칠 게 없다.** 진짜 위반이면 파일을 지우면 초록이 되지만, 오탐은 손댈 대상이 없어 빨간불이 그대로 남는다 → **빨간불이 기본값이 되고, 기본값이 된 신호는 아무도 안 읽는다.** 게이트의 존재 이유가 감지인데 감지 결과를 읽는 사람이 사라지면, 진짜 누출(시크릿·세션 트랜스크립트)이 발생해도 **같은 빨간불 안에 묻힌다.** 즉 이 고장은 "검사가 실패함"이 아니라 **"검사가 의미를 잃음"**이다.

- **해결**: 정규식을 **버리고**, whitelist의 소유자인 `.gitignore`에게 직접 물었다.

  ```bash
  git ls-files | git check-ignore --no-index --stdin
  ```

  추적 중인 파일에는 gitignore가 적용되지 않으므로(인덱스에 있으면 규칙을 건너뛴다) `--no-index`로 인덱스 상태를 무시하고 **규칙만** 평가한다. 여기 걸리는 파일 = "gitignore 상 무시돼야 하는데 추적되고 있다" = whitelist 위반이다. 정규식이라는 근사치가 아니라 **규칙 그 자체**라 더 정확하기도 하다.

  검사를 `scripts/check-tracked-whitelist.sh`로 빼 CI와 로컬이 같은 명령을 쓰게 했고(그 전까지 로컬에선 CI 로직을 손으로 재현했다), **붕괴 검사**를 하나 더했다 — `.gitignore`에서 `/*`가 사라지면 아무것도 무시되지 않아 위반 검사가 **언제나 0건인 빈 껍데기**가 된다. 통과하는데 검사하지 않는 상태라 통과율로는 안 잡힌다.

  다만 금지 시그니처 검사(`.jsonl`·credentials·shell-snapshots)는 **파생하지 않고 남겼다**. 그건 *gitignore가 실수로 열어줬을 때* 잡는 것이 목적이라, 같은 출처에서 파생하면 방어선의 의미가 사라진다.

- **재발방지**: **같은 목록을 두 곳에 적지 말고, 그 목록을 소유한 도구에게 물어라.** 이중 기재를 발견하면 "양쪽을 잘 맞추자"는 주석이 아니라 **파생 경로가 있는지**를 먼저 찾는다 — 주석은 소프트라 썩고, 실제로 이 레포는 그 주석을 달아둔 상태에서 `scripts/`를 열며 또 양쪽을 손으로 맞춰야 했다. 파생이 정말 불가능할 때만 이중 기재를 남기고, 그때는 검사기를 붙인다([T-041](T-041.md) 계열).

  판정 요령 하나: **오탐하는 검사는 실패한 검사보다 위험하다.** 실패는 고치면 끝나지만 오탐은 "고칠 게 없는데 빨갛다"라서 무시가 학습되고, 그 학습이 진짜 신호까지 덮는다. CI가 연속 실패 중이면 그 자체를 버그로 취급한다 — 「AI 활용 추적」이 남긴 *"규약은 불이행이 아니라 읽는 사람이 없어서 죽는다"*와 같은 병이고, [T-079](T-079.md)·[T-080](T-080.md)의 *"검증기가 스스로를 검증하지 않으면 조용히 죽는다"*의 CI판이다.
