# T-151 · 프로브 하네스 재사용이 곧 동일 동작이 아니다 — applyMorningEvent 누락으로 이벤트 0건

- **증상**: 제출 영상의 후반 컷 좌표를 역산하려고(2026-08-03) 기존
  `scripts/region-balance-probe.ts` 패턴을 복사해 이벤트 발생일을 측정했더니
  **84일 내내 아침 이벤트 0건**. 에러 없음 — 12주가 조용히 완주될 뿐이라,
  "이 시나리오에선 이벤트가 안 뜬다"는 오판으로 직행할 뻔했다.

- **원인**: 아침 이벤트는 하루 전이 함수 안에 있지 않다. UI(`SimGame.tsx`)는
  `applyMorningEvent(startNextDay(w))` / `applyMorningEvent(startNextWeek(w))`로
  **전이 후 이벤트 부착을 별도 호출**하는데, region-balance-probe는 밸런스
  장부만 재면 됐기에 `startNextDay`/`startNextWeek`만 부른다. 하네스를
  복사하면 그 생략까지 복사된다 — 이벤트가 영영 안 붙는 세계를 측정하게 된다.

- **해결**: 새 프로브(`scripts/cut-scenario-probe.ts` 등 4종)는 UI와 동일하게
  `applyMorningEvent(...)`로 전이를 감쌌다. 그 결과 시드 1의 84일 이벤트
  추첨표(첫 속보=1주 3일, LAWSUIT=12주 3일 단 하루)가 정확히 나왔고, UI
  실촬영에서 같은 날짜에 같은 이벤트가 떠 검증됐다.

- **재발방지**: 헤드리스로 "UI에서 벌어지는 판"을 재현할 땐 **SimGame이 부르는
  전이 호출렬을 그대로 복사**하는 것이 기준이다 — 기존 프로브 하네스는 "그
  프로브의 측정 목적"에 필요한 호출만 담고 있다. 재사용 전에 UI 쪽 호출렬과
  나란히 놓고 빠진 단계(이벤트 부착·자동 결산 가드 등)를 대조하라.
