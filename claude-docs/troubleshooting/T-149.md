# T-149 · NO_PEOPLE 엔딩은 어느 지역에서도 발화할 수 없다 — 의도된 「미용 무풍」의 창발적 부수 효과

- **증상**: 제출 영상 촬영 준비 중(2026-08-03) 엔딩 3종을 모두 담으려다 발견 —
  「사람이 바닥남」(NO_PEOPLE)이 어떤 플레이로도 나오지 않는다. 판정은
  `src/sim/week.ts` `endingOf`:

  ```ts
  const doctors = w.pawns.filter(p => p.kind === 'DOCTOR').length
  const leaving = resigningSimDoctors(w).length
  const poolLeft = Object.values(w.hirePool).reduce((sum, n) => sum + n, 0)
  if (doctors - leaving === 0 && poolLeft === 0) return 'NO_PEOPLE'
  ```

  `의사 0명` AND `전국 풀 전 과 합계 0`을 요구하는데, 이 둘이 동시에 참이 되는
  세계가 존재하지 않는다. 실측: URBAN 미용 1인 단독 12주 프로브에서 최대 피로 0
  (검증 스크립트 cut-*-probe.ts, untracked — 워크트리
  `game-graphics-implementation-d24800/scripts/`).

- **원인**: 세 사실의 합성이고, 셋 다 **각자는 의도된 설계**다.

  1. **의사가 떠나는 경로는 포화 사직뿐이다** — pawns에서 의사가 빠지는 곳은
     `startNextWeek`의 사직 집행 한 곳(해고 없음). 사직하려면 피로 100으로 마감한
     날(`saturatedDays`)이 임계에 닿아야 한다.
  2. **미용 의사는 피로 포화가 수학적으로 불가능하다** — 하루 600분(`DAY_END_MIN`)
     × 강도 0.3 = 표준강도분 상한 180. 무료 구간(`FATIGUE_FREE_MIN` 160)을 빼면
     초과 20분 → 하루 증가 상한 `round(20/60 × 15)` = **5** < 하룻밤 회복
     (`FATIGUE_REST`) **30**(2026-08-04 상향 전 20 — 간격이 벌어져 이 논지는 강해졌다).
     피로가 영영 누적되지 않는다. 이것은 버그가 아니라
     테스트로 잠근 의도다 — fatigue.test.ts 「미용 의사(강도 0.3)는 하루 종일 봐도
     무풍이다」, doctor.ts 주석 "저강도 과는 여전히 무풍이다", dept.ts 주석
     "미용으로만 굴리는 병원은 사직을 사실상 못 느낀다".
  3. **모든 지역 시작 풀에 미용이 있다** — 도심 8 · 신도시 8 · 소도시 4 · 농어촌 2
     (nationalPool 8 + 지역 델타).

  따라서 **미용을 안 뽑으면 `poolLeft ≥ 1`이 영원히 참이고, 뽑으면 그 의사가 영원히
  안 떠나 `doctors ≥ 1`이 영원히 참이다.** 어느 가지에서도 판정식의 AND가 성립하지
  않는다. 각 부품이 옳은데 합성이 도달 불가를 낳은 **창발적 결함**이라, 부품 단위
  테스트(전부 초록)로는 원리적으로 안 잡힌다 — 잡으려면 "이 엔딩에 도달하는 플레이가
  존재하는가"라는 **도달 가능성 축**의 검사가 따로 필요했다.

- **해결**: **코드 무변경 + 문서화**(사용자 결정 2026-08-03). 근거: ⓐ 마감(8/10)과
  Z9 코드프리즈(8/8)까지 5일 — 대안 (a) 미용 피로 튜닝은 테스트로 잠근 의도(무풍)와
  밸런스 전반(미용 흑자 엔진 논지)을 뒤흔들고, (b) 판정에서 미용 제외는 엔딩 의미
  ("더 뽑을 사람이 없다")와 서사 문구의 정합 재검토 + 테스트 수정이 필요하다.
  ⓑ 피해가 작다 — 12주차에 CAMPAIGN_END가 항상 발화하므로 좀비 판은 없고, 실피해는
  "엔딩 3종 중 1종이 실플레이·영상에 안 나온다"뿐이다. INSOLVENCY·CAMPAIGN_END는
  정상 도달 가능하다.

- **재발방지**: **"엔딩(또는 분기)이 존재한다"와 "도달 가능하다"는 다른 명제이고,
  후자는 부품 테스트의 합으로 증명되지 않는다.** 종결 조건이 여러 시스템(피로 곡선 ×
  과 카탈로그 × 지역 풀)의 AND일 때는, 조건마다 "이걸 참으로 만드는 경로가 실제로
  존재하는가"를 극단 빌드 프로브(1인 단독 12주 같은)로 한 번은 실측한다. 이 저장소의
  도구로는 `npm run probe` 계열이 그 자리다. 콘텐츠(엔딩·이벤트·대사 분기)를 새로
  달 때 "발화 조건을 만족시키는 세이브/시드를 하나 만들어 본다"를 완료 기준에 넣으면,
  이런 도달 불가가 출하 전에 걸린다 — 이번 건은 영상 촬영(= 전 엔딩을 실제로 띄우려는
  첫 시도)에서야 드러났다.
