# T-109 · 자식 캔버스가 부모 div의 background를 가린다 (배경 레이어 무성 실패)

- **증상**: 배경(backdrop) 캔버스를 TileMap transform div의 첫 자식으로 넣자 병원 부지 바닥(`OUTSIDE_FLOOR`)과 격자선이 화면에서 통째로 사라지고 전면이 풀밭으로 덮임. 빌드·타입·테스트 전부 통과 — 브라우저를 열어야만 보인다.
- **원인**: 설계 문서(2026-07-30-region-backdrop-design.md §5)가 "부지 안쪽은 그리지 않으면 부모 background가 보인다(캔버스는 뒤에 깔릴 뿐)"라고 전제했으나 **거꾸로다** — 자식 요소는 부모의 background **위에** 그려진다. 배경 12블록 중 11개가 `grass(0,0,EW,EH)`로 캔버스 전면을 칠해 부지 영역까지 불투명하게 덮었다.
- **해결**: 조립 함수 마지막에 `clearRect(부지 사각형)` 한 줄로 부지 영역을 투명으로 되돌려 부모 background(바닥+격자)가 비치게 함. 돌연변이(그 줄 제거) 시 부지 중앙 픽셀이 `rgba(0,0,0,0)` → 풀밭색으로 바뀌는 것을 브라우저 실측으로 확인.
- **재발방지**: transform div에 `absolute` 레이어를 더 얹을 때(미리보기·오버레이 등) "부모 background 위에 자식이 깔린다"를 전제로 z 설계를 검토한다. 회화 레이어는 단위 테스트가 없어 CI가 침묵하므로, 이런 변경은 브라우저 픽셀 실측(getImageData)으로 한 번 검증하고 커밋에 남긴다.
