# T-111 · 「카탈로그에서 파생하라」를 회귀 밴드에 적용하면 그 밴드는 아무것도 안 잠근다

- **증상**: 리뷰가 「외래 도착 배율의 절대값 밴드 테스트를 추가하라」고 지적했고(부분집합·단조만 재던 탓에 `NEWTOWN arrivalMul 1.2 → 1.05` 돌연변이가 생존), 이 저장소의 지배적 규약인 *「수치를 손으로 다시 적지 않는다」*를 그대로 따라 밴드를 이렇게 썼다:

  ```ts
  const mul = simRegion(region).arrivalMul          // ← 카탈로그에서 파생
  const ratio = arrivalMinutes(arrivalProbe(region)).size / urban
  expect(ratio).toBeGreaterThan(mul - 0.08)
  ```

  테스트는 초록이었다. 그런데 같은 돌연변이(1.2 → 1.05)를 다시 심자 **여전히 초록이었다** — 새로 추가한 밴드까지 포함해 5건 전원 통과. 리뷰가 잡으라고 한 바로 그 돌연변이를, 그것을 잡으려고 만든 테스트가 못 잡았다.

- **원인**: 기대값과 실측이 **같은 표**를 본다. 카탈로그의 `arrivalMul`을 1.05로 바꾸면 실측 비율이 1.05 근처로 내려가는데 기대 밴드도 `1.05 ± 0.08`로 함께 내려간다 — 두 변이 같은 방향으로 움직이므로 배율을 **어떤 값으로 바꿔도** 밴드는 영원히 초록이다. 이 테스트가 실제로 재고 있던 것은 "배율이 1.2인가"가 아니라 "곱셈이 곱셈으로 구현됐는가"뿐이었다.

  왜 밟았나: 이 저장소는 「이중 기재」를 세 곳에서 경고하고(옵시디언 태그 · changeLog PR 번호 · troubleshooting 목차), 같은 PR의 `simHud.regionRuleText`도 *"수치를 손으로 다시 적으면 값과 표시가 갈린다"*를 계약으로 삼는다. 그 규약이 **너무 잘 내면화돼** 예외 자리에까지 자동으로 적용됐다. 규약은 옳지만 적용 대상이 틀렸다 — **화면·파생 로직**은 카탈로그를 따라와야 하고, **회귀 잠금**은 따라오면 안 된다. 잠금의 목적이 바로 "따라오는 것을 막는 것"이다.

- **해결**: 밴드의 배율을 **리터럴로** 적었다 — 옆 파일의 응급 축(`emergency.test.ts`의 「건수가 카탈로그 배율에 붙는다 — 0.8 / 1.0 / 1.2」)이 처음부터 그렇게 쓰여 있었고, 그게 정답이었다.

  ```ts
  for (const [region, mul] of [['RURAL', 0.7], ['NEWTOWN', 1.2]] as const) { ... }
  ```

  같은 돌연변이를 다시 심으니 이번엔 죽었다(`NEWTOWN: expected 1.045… to be greater than 1.12`, 1건 실패). 그 자리에 **왜 리터럴인지**를 주석으로 못박아, 다음 사람이 「파생하라」 규약을 적용해 되돌리지 않게 했다.

  부수 발견: 표본 크기도 함께 고쳤다. tick 경로의 하루치 표본(≈180건)에서는 NEWTOWN 비율이 1.135로 ±0.08 밴드 가장자리에서 **0.015**밖에 안 떨어져 있어(1σ ≈ 0.05) 시드 하나만 바뀌어도 깨질 밴드였다. 응급 축처럼 40,320분 전수를 쓰려고 문턱 판정을 `patientFlow.arrivalAt`으로 export 했다(`emergencyArrivalAt`과 같은 자리) — 비율이 1.1962로 안정됐다.

- **재발방지**:
  - **「카탈로그에서 파생하라」는 화면·파생 로직의 규약이지 회귀 잠금의 규약이 아니다.** 값의 *부호·대소·존재*를 재는 테스트는 파생해도 되지만(그건 카탈로그가 바뀌어도 참이어야 하는 명제다), 값의 **크기**를 재는 테스트는 그 값을 **두 번째로 적어야** 성립한다. 두 벌이 갈리는 것이 사고가 아니라 **알림**인 유일한 자리다.
  - **밴드·스냅샷 테스트를 새로 쓸 땐 그 자리에서 돌연변이를 한 번 심어 본다.** 초록은 "잠갔다"의 증거가 아니다 — 이번 테스트는 추가된 순간부터 초록이었고, 초록인 채로 아무것도 안 잠그고 있었다.
  - **같은 축의 기존 테스트를 먼저 읽는다.** 응급 축에 이미 정답 형태가 있었는데(리뷰 지적문에도 "±0.08 밴드"라고 적혀 있었다) 형태만 베끼고 **리터럴이라는 핵심**을 규약으로 덮어썼다.
