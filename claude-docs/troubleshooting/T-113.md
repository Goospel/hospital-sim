# T-113 · 살아남은 돌연변이가 「테스트 구멍」이 아니라 **등가 돌연변이**일 때

- **증상**: 「지역이 규칙에 닿는다」 작업에서 도착·응급 배율 훅의 돌연변이 확인을 돌렸다. 19종 중 15종이 사살됐는데 **두 종이 살아남았다** — 외래와 응급 양쪽에서 *"배율을 문턱이 아니라 시드에 곱한다"* 변조다.

  ```ts
  // 원본
  const threshold = ARRIVAL_PROB_PER_MIN * arrivalProbMulOf(w) * simRegion(w.region).arrivalMul
  if (seededUnit(arrivalSeed(w)) >= threshold) return w

  // 심은 돌연변이 — 부분집합 테스트가 이걸 죽여야 한다고 봤는데 안 죽었다
  const threshold = ARRIVAL_PROB_PER_MIN * arrivalProbMulOf(w)
  if (seededUnit(arrivalSeed(w)) / simRegion(w.region).arrivalMul >= threshold) return w
  ```

  설계가 명시적으로 "이 돌연변이를 죽여라"고 지목한 계약(`patientFlow.test`의 도착 분 부분집합)이라, 첫 판단은 **"내 테스트가 공허하다"**였다. 부분집합 단언을 더 촘촘히 고쳐야 하나로 30분쯤 갈 뻔했다.

- **원인**: 그 돌연변이는 **원본과 대수적으로 같은 식**이다. `u / m >= t` ⟺ `u >= t * m` (m > 0). 즉 소스는 달라졌지만 **판정 결과가 모든 입력에서 동일**하다 — 관측 가능한 동작이 하나도 안 바뀌었으니 어떤 테스트도 죽일 수 없고, 죽인다면 그게 오히려 버그다(구현 세부를 재는 테스트라는 뜻).

  내가 "시드에 곱하기"라고 **이름 붙인 것**이 오해의 근원이었다. 진짜 시드 변조는 시드의 **입력**을 바꿔 도착 시각의 배열 자체를 갈아 끼우는 것인데, 내가 심은 것은 시드가 낳은 **출력값**을 나눈 것이라 문턱을 곱하는 것과 같은 연산이다. 라벨이 의도를 말했고 코드는 다른 일을 했다.

  ```ts
  // 진짜 시드 변조 — 이건 즉시 사살됐다(부분집합이 깨진다)
  const rm = simRegion(w.region).arrivalMul
  if (seededUnit(arrivalSeed({ ...w, seed: w.seed + Math.round(rm * 10) })) >= threshold * rm) return w
  ```

- **해결**: 생존 판정을 받은 즉시 **테스트를 고치기 전에 돌연변이의 등가성을 먼저 확인**했다. 두 줄짜리 부등식 변형이라 종이에서 끝났다. 그다음 같은 *의도*(도착 시각의 배열을 갈아 끼운다)를 실제로 구현하는 돌연변이로 다시 심었고, 외래·응급 양쪽에서 부분집합 단언이 죽였다. 테스트는 한 줄도 안 고쳤다 — **고칠 것이 없었다.**

- **재발방지**:
  - **생존한 돌연변이의 첫 용의자는 테스트가 아니라 돌연변이 자신이다.** 순서를 못박는다: ① 이 변조가 관측 가능한 동작을 정말 바꾸는가(등가식이 아닌가) → ② 바꾼다면 그 차이가 어떤 입력에서 드러나는가 → ③ 그제서야 테스트를 의심한다. 거꾸로 가면 멀쩡한 테스트를 구현 세부에 묶는 방향으로 "고치게" 된다 — **등가 돌연변이를 죽이려는 테스트는 정의상 리팩터링을 깨뜨리는 테스트다.**
  - **곱셈·나눗셈·부등호가 얽힌 판정식은 특히 위험하다.** `u >= t*m` / `u/m >= t` / `u*(1/m) >= t`가 전부 같은 식이라, "다른 자리에 곱했다"는 서술이 곧 "다른 동작"을 뜻하지 않는다. 이 저장소가 반복해서 쓰는 *"시드가 아니라 문턱에 곱한다"* 계약은 **곱하는 자리**가 아니라 **시드 입력을 건드리는가**로 판별해야 한다.
  - 돌연변이 목록에 라벨을 적을 때 **그 라벨이 코드와 같은 말인지** 한 번 읽는다. [T-108](T-108.md)이 같은 스크립트에서 "1개는 등가 돌연변이로 판정"을 이미 한 번 기록했는데, 그때는 개별 사례로 흘렸다 — 두 번째 관측이라 항목으로 세운다.
